# 数据池模块 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 实现独立「数据池」模块：平台可注册管理多个外部数据库连接（MySQL/PostgreSQL/H2，方言可插拔），管理员在前端可视化增删改、测试连通、切换当前连接、浏览库表与数据预览；配置存平台库，预留分布式拓展。

**架构：** 后端新增 `datasource` 包：`dialect`（可插拔方言）+ `pool`（HikariCP 连接池注册表）+ `util`（AES 加密）+ `entity/dto/mapper/service/controller`（连接器管理）。复用已有 `connector` 表（V3 迁移扩字段）。前端改造「数据接入」页接真实接口。

**技术栈：** Spring Boot 3.3.5 + MyBatis-Plus 3.5.7 + HikariCP（内置）+ JDBC（MySQL/PG/H2 驱动）+ AES-GCM；前端 Vue3 + TS + Vite。

**设计规格：** `docs/superpowers/specs/2026-08-16-数据池模块-设计方案.md`

```java
// ConnectorDbType.java
public enum ConnectorDbType {
    MYSQL("mysql"), POSTGRESQL("postgresql"), H2("h2");
    private final String code;
    ConnectorDbType(String code) { this.code = code; }
    public String getCode() { return code; }
    public static ConnectorDbType from(String code) {
        for (ConnectorDbType t : values()) if (t.code.equalsIgnoreCase(code)) return t;
        throw new BusinessException(ResultCode.BAD_REQUEST.getCode(), "不支持的数据库类型: " + code);
    }
}
```

```java
// DbDialectFactory.java
public final class DbDialectFactory {
    private DbDialectFactory() {}
    public static DbDialect of(ConnectorDbType type) {
        switch (type) {
            case MYSQL: return new MySqlDialect();
            case POSTGRESQL: return new PostgreSqlDialect();
            case H2: return new H2Dialect();
            default: throw new BusinessException(ResultCode.BAD_REQUEST.getCode(), "未支持的数据库类型");
        }
    }
    public static DbDialect ofCode(String code) { return of(ConnectorDbType.from(code)); }
}
```

```java
// AesUtil.java @Component
public class AesUtil {
    private static final String TRANSFORM = "AES/GCM/NoPadding";
    private final SecretKey key;
    public AesUtil(@Value("${datalink.crypto.key}") String keyHexOrRaw) {
        byte[] bytes = keyHexOrRaw.getBytes(StandardCharsets.UTF_8);
        if (bytes.length != 16 && bytes.length != 24 && bytes.length != 32)
            throw new IllegalStateException("datalink.crypto.key 需 16/24/32 字节");
        this.key = new SecretKeySpec(bytes, "AES");
    }
    public String encrypt(String plain) { /* GCM: 12 字节随机 IV 前置密文，Base64 输出 */ }
    public String decrypt(String cipher) { /* 解析 IV + 密文，GCM 解密 */ }
}
```
> 实现要点：`Cipher` 用 `AES/GCM/NoPadding`，`GCMParameterSpec(128, iv)`，IV 用 `SecureRandom` 生成 12 字节并拼在密文前；加密返回 Base64。

```java
// ConnectionPoolRegistry.java @Component
public class ConnectionPoolRegistry {
    private final Map<Long, HikariDataSource> pools = new ConcurrentHashMap<>();
    private final AesUtil aesUtil;
    public ConnectionPoolRegistry(AesUtil aesUtil) { this.aesUtil = aesUtil; }

    public DataSource get(Connector c) {  // 懒加载；参数变化调用 evict 后重建
        return pools.computeIfAbsent(c.getId(), id -> build(c));
    }
    public void evict(Long id) { HikariDataSource ds = pools.remove(id); if (ds != null) ds.close(); }
    public void closeAll() { pools.values().forEach(HikariDataSource::close); pools.clear(); }

    private HikariDataSource build(Connector c) {
        DbDialect d = DbDialectFactory.ofCode(c.getDbType());
        HikariConfig cfg = new HikariConfig();
        cfg.setDriverClassName(d.driverClass());
        cfg.setJdbcUrl(d.buildJdbcUrl(c.getHost(), c.getPort() == null ? 0 : c.getPort(), c.getDatabaseName()));
        cfg.setUsername(c.getUsername());
        cfg.setPassword(aesUtil.decrypt(c.getEncryptedPwd()));
        cfg.setPoolName("datalink-conn-" + c.getId());
        cfg.setMaximumPoolSize(5);
        cfg.setConnectionTimeout(10_000);
        cfg.setValidationTimeout(5_000);
        return new HikariDataSource(cfg);
    }
}
```

- [ ] **步骤 2：实现关键逻辑（注入 ConnectorMapper / AesUtil / ConnectionPoolRegistry）**

核心要点：
- `create`：`dbType` 用 `ConnectorDbType.from` 校验；`password` 必填（空抛 `BusinessException(400,"密码不能为空")`）；AES 加密存 `encryptedPwd`；`connectorType="DB"`；返回 VO（脱敏）。
- `update`：先查存在（不存在抛 `BusinessException(NOT_FOUND.getCode(),"连接不存在")`）；`password` 非空才重加密；改后 `poolRegistry.evict(id)`；参数变化（host/port/db/账号）重建池。
- `delete`：`poolRegistry.evict(id)` 后逻辑删除（`enabled=0`）或物理删除——**本计划用物理删除**（`deleteById`），简单明确。
- `test(id)`：不用连接池，`DriverManager.getConnection(url,user,pass)` 带 `DriverManager.setLoginTimeout(5)`；成功回 `TestResult{ok=true, latencyMs, dbVersion=conn.getMetaData().getDatabaseProductName()+"/"+getDatabaseProductVersion()}`；失败回 `TestResult{ok=false, message=异常简短信息}`（**不打印密码/URL**）；成功后更新 `lastTestStatus='OK'`、`lastTestTime=now`，失败更新 `'FAIL'`。
- `activate(id)`：`@Transactional` —— `UPDATE connector SET is_active=0 WHERE is_active=1`；再把目标 `is_active=1`。校验目标存在且 `enabled=1`。
- `tables(id)`：从连接池取连接（`conn.setReadOnly(true)`），用 `DatabaseMetaData.getTables(null, schemaNameOrNull, "%", new String[]{"TABLE","VIEW"})` 收集；失败抛 `BusinessException(400, "连接失败: "+msg)`。
- `preview(id, table)`：`d.previewSql(table, 50)` 走连接池（只读），取 `ResultSetMetaData` 列名 + 行数据（`rs.next()` 前 50 行），`rowCount` 返回实际行数。
